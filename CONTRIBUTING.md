# Contributing to AI-Powered ATS Resume Builder Platform

Thank you for your interest in contributing to the AI-Powered ATS Resume Builder Platform!

## Code of Conduct
We are committed to providing a friendly, safe and welcoming environment for everyone, regardless of gender, sexual orientation, disability, ethnicity, or religion.

## Getting Started
1. Fork the repository on GitHub.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/pugalsandy55/Testing-.git
   cd Testing-
   ```
3. Create a branch for your feature or bugfix:
   ```bash
   git checkout -b feature/amazing-feature
   ```

## Development Workflow
- **Frontend**: Navigate to `frontend/`, run `npm install`, then `npm run dev`.
- **Backend**: Navigate to `backend/`, create a virtual environment, install requirements, and run `uvicorn main:app --reload`.
- Ensure all tests pass before submitting a Pull Request.

## Pull Request Guidelines
- Follow existing code formatting and styling conventions.
- Provide descriptive commit messages.
- Ensure all unit and integration tests pass.
- Update documentation when adding new features or changing APIs.
